# 🌍 COVID-19 Data Analysis & Visualization

## 📌 Project Overview
This project focuses on analyzing the global impact of COVID-19 using real-world data. The goal is to extract meaningful insights, identify trends, and visualize the spread of the pandemic across different countries and regions.

Using Python and data visualization techniques, this project explores confirmed cases, deaths, recoveries, and active cases to better understand the progression of COVID-19 over time.

---

## 📊 Dataset Information
- **Dataset Name:** Corona Virus Report
- **Source:** Kaggle  
- **Link:** https://www.kaggle.com/datasets/imdevskp/corona-virus-report  

### 📁 Key Features:
- Country/Region-wise data
- Date-wise progression
- Confirmed cases
- Death cases
- Recovered cases
- Active cases
- Province/State (where available)

---

## 🎯 Objectives
- Analyze global COVID-19 trends over time  
- Identify top affected countries  
- Compare confirmed, death, and recovery cases  
- Calculate mortality and recovery rates  
- Build meaningful visualizations for better understanding
